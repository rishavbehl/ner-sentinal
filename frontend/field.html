Why offline-first

Large parts of the North East have no usable mobile data exactly where the roads fail. This page is a service-worker PWA: it loads from cache with no network, stores your reports in IndexedDB, and replays them to the control room when connectivity returns. Each report carries a client ID so a retry can never create a duplicate.
